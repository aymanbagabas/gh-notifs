# Responsive upload scenario

This is fictional presentation content, not a product change.

## Expected behavior

1. Show pending progress when the upload starts.
2. Keep keyboard navigation available during the request.
3. Show success only after the response arrives.
4. On failure, explain the error and preserve the selected file.

## Manual walkthrough

Select a file, start the upload, and move focus with the keyboard.
Confirm that the progress indicator changes before the response.
Repeat with a failed request and inspect the error.
